# 营销诊断 API — 接口文档

> 面向**调用方**的接口参考文档:怎么下单、怎么轮询、怎么取出参、出错怎么看。

---

## 1. 接口概述

本接口接收营销活动 ID,异步执行营销诊断分析,最终产出:

- **诊断报告链接**(HTML 页面)
- **人群推送规则 JSON**(含可直接在 Hive 执行的圈人 SQL)

接口不写任何表、不导入人群表、不落库,仅输出分析结果。

---

## 2. 服务地址

| 环境 | Base URL |
|---|---|
| **生产(网关)** | `https://friday_deployment_14540_algo_agent.gw.friday.17usoft.com` |

所有接口路径均以 `/api/ma` 为前缀,拼接在 Base URL 之后。

---

## 3. 鉴权

所有接口(除 `GET /healthz`)均需在请求头中携带 API Key:

```
x-ma-api-key: <你的 API Key>
```

API Key 由服务端分配,调用方在请求头中传入即可。

---

## 4. 请求限制

- 请求体上限:**64 KB**,超出返回 `413`。
- Content-Type:`application/json`。

---

## 5. 接口清单

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/healthz` | 否 | 健康检查,返回服务状态 |
| POST | `/api/ma/diagnose` | 是 | 下单,同步返回 `202` + `job_id`,后台异步执行 |
| GET | `/api/ma/jobs` | 是 | 列任务 |
| GET | `/api/ma/jobs/{id}` | 是 | 查任务状态 + 日志流水 |
| GET | `/api/ma/jobs/{id}/result` | 是 | 取出参(任务未完成时返回 `409 E_NOT_READY`) |

> 路径为**精确白名单**,不支持前缀通配。未列出的路径返回 `404 E_NOT_FOUND`。

---

## 6. 下单接口(`POST /api/ma/diagnose`)

### 6.1 请求参数

请求体为 JSON 对象,**只接受以下三个字段**:

| 字段 | 必填 | 类型 / 约束 | 说明 |
|---|---|---|---|
| `activity_id` | 是 | 字符串,正则 `^[A-Za-z0-9_\-]{1,64}$` | 营销活动 ID。**必须为真实活动 ID**,虚假 ID 不会报错,但会产出空白报告 |
| `date` | 否 | 字符串,`YYYY-MM-DD` | 数据日期,不传则默认当天 |
| `meta` | 否 | JSON 对象 | 活动元信息,见下表 |

`meta` 对象可包含以下子字段:

| 子字段 | 类型 / 约束 | 说明 |
|---|---|---|
| `campaign_name` | 字符串 | 活动名称,用于报告展示 |
| `campaign_type` | 字符串,≤64 字符 | 活动类型(如:私域、活动等),默认为"活动"。**必须放在 `meta` 内,不能放在顶层** |
| `target_products` | 字符串数组 | 目标品类名(如:机票、酒店等),非页面名。不传则从数据自动推断 |

  "date": "2026-07-30",
  "meta": {

## 8. 任务状态与出参

### 8.1 任务状态机

任务终态只有两个:`done`(成功)/ `error`(失败)。其余均为中间态。

中间态通过 `state` + `phase` 字段标识:

| `state` | `phase` | 说明 |
|---|---|---|
| `pending` | — | 已入队,等待执行 |
| `running` | `pull` → `prepare` → `thresholds` → `draft` → `crowd_rules` → `crowd_push` → `report_agent` → `polish` → `self_critique` → `render` → `publish` → `assemble` | 执行中,`phase` 标识当前阶段 |
| `done` | — | 执行完成 |
| `error` | — | 执行失败 |

**并发约束:**

- 同一 `activity_id` 已有任务在执行时,再次下单返回 `409 E_ACTIVITY_BUSY`。
- 任务未完成时请求 `/result` 返回 `409 E_NOT_READY`。
- 任务失败时请求 `/result` 返回 `409` + 对应错误码。

### 8.2 出参字段(`/api/ma/jobs/{id}/result`)

任务成功后,`/result` 接口返回以下字段:

| 字段 | 类型 | 说明 |
|---|---|---|
| `job_id` | string | 任务 ID |
| `state` | string | 任务状态:`done` / `error` |
| `activity_id` | string | 回显的活动 ID |
| `mode` | string | 执行模式:`C` / `B` |
| `report_url` | string | 诊断报告链接(HTML 页面),需在公司网内访问 |
| `rules` | array | 人群推送规则明细,每条包含 `finding_id`、`direction`、`name`、`sql_filter` |

### 8.3 降级标志

出参中可能包含以下降级标志,用于标识产出质量:

| 标志 | 含义 |
|---|---|
| `degraded` | 执行过程中走了兜底路径 |
| `skill_degraded` | 分析 skill 侧发生降级 |
| `render_forced` | 报告为强制产出,正文可能残留草稿骨架句 |

> 以上标志均为 `false` 时,表示一轮完整干净的产出。任一为 `true` 时,出参仍可用,但建议人工复核 `warnings` 字段。

## 9. 错误码

| HTTP 状态码 | 错误码 | 触发条件 |
|---|---|---|
| 400 | `E_BAD_REQUEST` | JSON 解析失败 |
| 400 | `E_BAD_PARAM` | 入参出现 `activity_id` / `date` / `meta` 以外的键(如 `push_source` / `pull_partition` / `note` / 顶层 `campaign_type`) |
| 400 | `E_BAD_ACTIVITY_ID` | `activity_id` 缺失或不符合 `^[A-Za-z0-9_\-]{1,64}$` |
| 400 | `E_BAD_DATE` | `date` 格式不是 `YYYY-MM-DD` |
| 400 | `E_BAD_META` | `meta` 不是 JSON 对象 |
| 401 | `E_UNAUTHORIZED` | 缺少或错误的 `x-ma-api-key` 请求头 |
| 404 | `E_NOT_FOUND` | 请求路径不在接口白名单中 |
| 404 | `E_JOB_NOT_FOUND` | 任务 ID 不存在 |
| 405 | — | 路径正确但 HTTP 方法不对(如 `GET /api/ma/diagnose`) |
| 409 | `E_ACTIVITY_BUSY` | 同一 `activity_id` 已有任务正在执行 |
| 409 | `E_NOT_READY` | 请求 `/result` 时任务尚未完成 |
| 409 | `<任务错误码>` | 任务执行失败 |
| 413 | — | 请求体超过 64 KB |

---

## 10. 注意事项

- **`activity_id` 必须为真实活动 ID。** 虚假 ID 不会报错,但会产出空白报告,难以排查。
- **`target_products` 传品类名**(如:机票、酒店),不是页面名。不传则从数据自动推断。
- **`push_source` 不支持入参配置。** 传入会被 `400` 拒绝。
- **只输出推送(push)人群规则。** 排除(exclude)规则仅做审计留痕,不包含在出参中。
- **报告链接需在公司网内访问验证。**
